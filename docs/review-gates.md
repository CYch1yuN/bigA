# Codex 审核闸门

审核结果仅允许为 `PASS`、`PASS WITH FIXES` 或 `FAIL`。

## Gate 1：数据层

- 原始、清洗和元数据分层明确，可追溯到数据源和抓取时间。
- 复权价格只用于信号，未复权价格用于成交。
- 保留上市、退市、停牌、名称及 ST 状态历史，不使用当前股票列表替代历史股票池。
- 自动检测重复、缺失交易日、OHLC 关系错误、负值、异常成交量和跨源差异。
- 数据质量失败必须阻止下游执行，并产生机器可读与 Markdown 报告。
- 固定输入、配置和代码版本可产生一致结果。

## Gate 2：回测器

- 收盘后生成信号，最早下一交易日开盘成交。
- 正确模拟 100 股整数倍、资金不足、T+1、停牌、涨跌停和可配置费用。
- 每笔订单都记录信号、尝试成交、成交或拒绝原因。
- 人工可核对案例与防未来函数测试通过。
- 现金、持仓与权益每日满足账务恒等式；金额和费用计算可确定复现。
- 成功、拒绝和期末取消订单均保留审计记录，报告指标可由原始流水独立复算。
- Phase 1全部测试继续通过，回测核心包覆盖率不低于90%。

## Gate 3：策略层

- 展示完整样本和滚动样本外结果，不只展示最佳区间或参数。
- 执行费用、滑点、参数扰动和市场阶段压力测试。
- 稳健轨最大回撤超过 20% 或扣费后无稳定正期望时，结论为“不具备实盘资格”。
- 激进轨只报告十倍、亏损 50% 和近似归零概率，不给出收益承诺。

## Gate 4：自动化

- 交易日 18:30 后按数据更新、质量检查、信号、模拟账户、报告顺序执行。
- 有锁文件、幂等重跑、失败停止、结构化日志和失败告警。
- 连续模拟 60 个交易日无静默错误、重复订单或无法解释的权益变化。
