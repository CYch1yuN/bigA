# 未来升级路线图

更新时间：2026-08-03

## 当前定位

项目已经完成数据层、A 股事件驱动回测、双轨策略研究、本机自动化、模拟账户、westock 旁路核验和可操作 Dashboard。当前仍是**研究与模拟系统**，不连接券商、不操作真实资金。

当前主线是 **Phase 4 / Gate 4B 连续运行验证**：60 日历史回放已经通过，但真实连续运行尚未开始（0/60），真实行情成功产出仍需在可访问行情接口的网络环境验证。

## 现在可以执行的升级（P0）

这些工作不依赖 60 日观察完成，可以立即推进。

1. **真实行情首跑与运行诊断（已于 2026-08-03 完成首跑）**
   - 在网络可用环境完成一个真实交易日的完整 daily 流程。
   - 核对 curated 行情、数据清单、质量报告、信号、模拟订单、账户净值与 Dashboard 展示。
   - 固化数据源连接诊断、代理检查、失败原因分类和重试耗时指标。
   - 首跑结果：业务日 2026-07-31，BaoStock 备用源接管 8/8 标的，取得 2,144 行真实行情，质量闸门 0 critical / 0 warning，生成 17 个运行产物。
   - westock 旁路核验：对首跑 8 只标的拉取未复权日线并与 curated 交叉比较，全部通过——close 最大偏差 0、volume 最大约 0.0009%（手→股换算后仅取整差异）、amount 最大约 0.0003%；westock 仍仅作旁路核验，不进回测主链。
   - 待修复项：AKShare 主源不可用、沪深 300 基准未取得、westock hook 尚未注入。此次为手工重跑，不计作 Gate 4B 正式连续运行。

2. **启动 Gate 4B 连续 60 交易日观察**
   - 启用每日 18:30 自动任务，按真实交易日累计进度。
   - 记录成功、失败、跳过、恢复、重复订单和账务恒等式结果。
   - 明确验收指标：运行成功率、数据覆盖率、告警可达性、恢复时间和对账误差。

3. **运行监控与对账看板**
   - 展示行情最新业务日、缺失标的、主备源差异和 westock 核验趋势。
   - 增加“信号 → 风控 → 订单 → 成交/拒绝”漏斗。
   - 展示现金、持仓市值、费用、权益恒等式及回测预期与模拟成交偏差。
   - 增加连续 skipped、数据过期、净值断点和作业失败告警。

4. **实验与产物治理**
   - 建立实验注册表，绑定代码提交、数据哈希、配置哈希和结果哈希。
   - 保留失败实验和全部参数搜索记录，禁止只留最佳结果。
   - 为 Dashboard 增加作业详情、逐步骤日志和产物入口。

5. **数据基础审计**
   - 盘点历史 ST、上市、退市、停牌和行业分类覆盖率。
   - 输出 point-in-time 股票池缺口报告，缺失状态不得静默按当前状态回填。
   - 持续观察腾讯自选股复权参数；修复前只保留旁路核验定位。

## 真实首跑后推进（P1）

1. **公司行为与总收益核算**
   - 支持现金分红、送转股、拆并股和配股。
   - 信号继续使用复权价格，成交和持仓账本使用原始价格与公司行为流水。
   - 引入总收益基准，完成跨年度持仓核算与审计样例。

2. **成交真实性与策略容量**
   - 增加成交量参与率、动态滑点、市场冲击和流动性容量限制。
   - 建模一字板、涨跌停排队、停牌恢复和开盘跳空。
   - 用不同资金规模复跑，输出收益、回撤、换手和成交率的容量曲线。

3. **研究防过拟合体系**
   - 增加 purged/embargo 时间序列验证、多重检验修正和参数稳定性分析。
   - 输出 IC、Rank IC、信号衰减、分组收益和换手成本。
   - 严格隔离训练、验证、测试和上线观察窗口。

4. **组合风险模型**
   - 增加单股、行业、风格、流动性和集中度约束。
   - 支持波动率目标、风险预算、最大回撤降仓和基准相对暴露。
   - 组合目标中显式计入佣金、滑点与换手惩罚。

## Gate 4B 后评估（P2）

- 评估模拟账户与回测结果的长期偏差和策略漂移。
- 建立数据源 SLA、备份恢复、状态迁移和灾难恢复演练。
- 根据连续观察结论决定是否继续扩大模拟资金规模和策略池。
- 只有经过独立复审并重新定义安全边界后，才能讨论券商接口；当前项目继续永久禁止实盘路径。

## 暂缓事项

- 券商连接、真实下单和真实账户读取。
- 在数据与研究治理未完成前引入强化学习或复杂深度学习模型。
- 为追求更好回测曲线而增加大量指标、频繁调参或更换测试区间。
- 将 westock 未验证的复权结果用于回测主链。
