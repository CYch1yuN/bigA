# Trae 任务：Phase 1 数据层

## 角色与边界

你是本阶段实现者，使用 GLM-5.2 完成代码、测试和文档。仅实现数据层；不得开始回测器、策略或自动交易。不得修改本文件的验收标准以迁就实现。

工作目录为本 Git 仓库。创建并使用分支 `trae/phase-1-data`。如果尚未配置 GitHub remote，先完成本地实现并在最终报告中明确标记，不要自行创建或猜测远程仓库。

## 技术要求

- Python 3.11+，使用 `src` 布局；依赖至少包含 DuckDB、PyArrow、Pandas 或 Polars、Pydantic、PyYAML、pytest。
- 定义统一 `DataProvider` 抽象；AKShare 为主实现，BaoStock 为备用实现。网络访问必须与清洗和校验逻辑解耦，测试不得依赖实时网络。
- 数据分为 `raw`、`curated`、`metadata`；默认写入 Git 忽略的数据目录，Parquet 存储、DuckDB 查询。
- 日行情的规范字段至少包含：股票代码、交易日、未复权 OHLC、成交量、成交额、前复权 OHLC、复权因子、停牌/可交易状态、数据源和抓取时间。
- 证券主数据至少包含：股票代码、名称、上市日、退市日、ST 状态生效区间和板块；不得用当前股票列表代表历史股票池。
- 提供数据版本清单，记录数据源、抓取区间、行数、文件 SHA-256、配置摘要和代码提交号。
- 实现重复键、缺失交易日、OHLC 关系、负价格/成交量、复权连续性、异常跳变和双源容差比较。
- 严重质量问题返回非零退出码并阻止后续步骤；同时生成 JSON 和 Markdown 报告。
- 凭据只允许从环境变量读取；提供 `.env.example`，不得写入真实值。

## 必须测试

- 使用仓库内的小型合成样本覆盖正常数据、重复行、缺失交易日、停牌、退市、异常 OHLC、异常成交量和跨源冲突。
- 证明相同输入和配置产生相同的 curated 数据与版本清单；抓取时间等非确定字段不得破坏内容复现测试。
- 证明信号使用列与未复权成交列在 schema 中明确分离。
- 所有测试离线运行，单元测试不得调用 AKShare/BaoStock 服务。

## 交付物

- 可安装的项目骨架、锁定或带上限的依赖声明、CLI 使用说明和 `.gitignore`。
- 数据提供器、标准化、存储、质量检查、清单生成模块及测试。
- `reports/phase-1/` 下的示例覆盖报告、异常报告和最小可复现数据说明。
- `docs/phase-1-limitations.md`，如实记录免费数据源、退市/ST 历史和复权数据的已知缺口。
- 最终回复列出实际运行过的命令、测试结果、未完成项和建议审核重点；禁止只提供收益或截图。

## 完成条件

运行完整测试套件并确认没有真实密钥或完整行情数据进入 Git。完成后停止，等待 Codex Gate 1 审核，不得自行进入 Phase 2。
